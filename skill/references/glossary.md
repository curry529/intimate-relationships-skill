# GLOSSARY — 《亲密关系》关键术语词典

> 按作者本人用法整理；共享词典，随 bundle 分发。

## 关系基础
- **亲密关系**：在了解、关心、相互依赖、相互一致性、信任、承诺六方面程度高的关系（程度连续变量，挚友亦可，非恋爱专属）。
- **亲密关系六维**：了解、关心、相互依赖、相互一致性、信任、承诺。
- **依恋类型**：由抚育互动形成、落在"回避亲密×忧虑被弃"两维的人际联结模式，可随经历改变。
  - **安全型**（低回避低忧虑）、**焦虑-矛盾/痴迷型**（低回避高忧虑）、**恐惧型**（双高）、**疏离/拒绝型**（高回避低忧虑）。
- **性生理差异 / 性认同差异**：前者是生理身体差异；后者是社会化的男性化/女性化角色差异，须分开。
- **工具性 / 表达性**：果断独立任务取向 / 热情温柔关系取向；两者兼具（双性化）适应更佳。
- **演化心理学 / 亲代投入**：以自然选择与两性养育投入差异解释择偶、性、嫉妒；多为事后假说，应作视角。

## 吸引与认知
- **适配价值**：个体作为伴侣的总体合意度；人们多做等值匹配。
- **曝光效应**：重复接触提升喜欢（初始负面时相反）。
- **宿命信念 / 成长信念**：天定无需努力 / 靠经营可改变；后者导向解决问题。
- **行动者-观察者效应**：对自己怪情境、对他人怪人格的归因偏差。
- **自利偏差**：成功归己、失败归人。
- **自我实现预言**：预期通过引导行为而最终成真。
- **印象管理**：影响他人对自己印象的策略（逢迎、自我推销等）。

## 沟通
- **非言语沟通 / 副语言**：表情、注视、动作、触摸、距离，及语调、节奏、停顿（不含内容）。
- **自我表露**：向他人透露私密信息与感受，互惠渐进才增进亲密。
- **知觉检验**：用中性问句核实对对方情绪意图的理解，防读心。
- **XYZ 句式**："当你在 X 情境做 Y 时，我感到 Z"，行为描述+我陈述的组合。

## 相互依赖
- **结果**：奖赏 − 代价。
- **比较水平 CL**：自认应得水平，结果−CL 决定满意度。
- **替代比较水平 CLalt**：离开转向替代/独处的预期结果，结果−CLalt 决定稳定性。
- **较小利益原则**：更不依赖、更易离开的一方权力更大。
- **共有关系 / 交换关系**：因需要而付出不即时清算 / 讲求对等偿还；亲密关系应偏共有但需总体公平。
- **投资模型**：承诺 = 满意度 + 替代质量 + 投入规模。
- **公平理论**：双方投入∶所得比相称；获益不足与过度获益都制造紧张。

## 关系形态
- **应答性**：被认知、尊重、恰当回应需要的程度，友谊与爱情的核心。
- **社会支持三类型**：感情支持、信息支持、工具支持。
- **社会情绪选择理论**：未来时间感决定重信息功利（广交友）还是重情感（收缩至亲）。
- **羞怯 / 孤独**：怕拒而拘谨被误读高冷 / 归属需要未满足并自我恶化。
- **爱情三角理论**：亲密、激情、承诺三成分组合成不同爱情类型。
- **浪漫之爱 / 相伴之爱**：亲密+激情 / 亲密+承诺；后者更稳定。
- **社会性性行为取向 SOI**：对无承诺性行为的接受度（保守—开放），比性别更能预测出轨。

## 故障与终结
- **反应性嫉妒 / 怀疑性嫉妒**：对真实威胁 / 无据猜疑。
- **情境性伴侣暴力 SCV / 亲密恐吓 IT / 暴力抵抗 VR**：冲突中偶发冲动 / 系统性控制会升级 / 受害者反击。
- **I立方模型**：激发因素 × 促动因素 ÷ 抑制因素；抑制强则暴力不发生。
- **障碍模型**：分手由吸引力、替代选择、离开障碍共同决定。
- **脆弱-应激-适应模型**：持续脆弱 × 压力事件 × 应对能力决定婚姻结果。
- **幻灭模型**：早期浪漫情感的急剧下降最能预测离婚。
- **Duck 解体五阶段**：个人 → 双人 → 社交 → 善后 → 复兴。
- **宽恕三条件**：真诚道歉不再犯、共情、放弃报复。
- **米开朗基罗现象**：帮助彼此趋近各自理想自我。
