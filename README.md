# intimate-relationships · 亲密关系 AI 技能与话术手册

把社会心理学经典《亲密关系》（罗兰·米勒，第6版）中的方法论，蒸馏成可被 AI 调用的技能，
并整理成普通人能直接照说的话术手册。

## 目录
- `skill/` — 单入口 AI 技能（含 19 张能力卡、术语表、速查表、概览）
- `buyer-manual/亲密关系话术速查手册.pdf` — 30 秒上手的买家版手册（A4）

## 19 个能力
依恋模式 / 吸引择偶 / 信念归因 / 非言语信号 / 精确表达 / 倾听共情 / 满意度与稳定性 /
承诺投资 / 公平规范 / 友谊与孤独 / 爱情类型与保鲜 / 性沟通安全 / 嫉妒 / 背叛与宽恕 /
冲突管理 / 权力平衡 / 暴力安全 / 分手离婚 / 关系维持修复。

## 怎么用
- **不折腾**：打开 PDF，按"场景速查表"找到你的情况，翻到对应页照着说。
- **用 AI**：把 `skill/SKILL.md` 发给豆包/ChatGPT，说"按这个来"，再描述你的具体情况。

## 边界
- 本项目为自制转化性学习笔记与话术，**不含原书文本**，非官方、非授权电子书。
- 实证多为 2010 年前后美国样本，跨文化与数字时代需降级；情感问题仅供参考，重大决定自行判断。
- 出现现实暴力/威胁时，安全优先，必要时联系紧急服务。
